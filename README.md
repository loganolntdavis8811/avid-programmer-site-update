## Project Overview

Avid Programmer is a personal website created with HTML and structured for static hosting. Because it does not depend on a server-side runtime, the pages can be opened directly in a browser and maintained as source files.

This repository offers programmers a lightweight way to manage an online presence through Git and GitHub Pages. Publishing consists of changing the site files, committing those edits, and pushing them to the configured repository.

---

## What It Includes

- Static site architecture
- Pages written in HTML
- Website content accessible through a browser
- Compatibility with GitHub Pages hosting
- Publishing managed through the repository
- A straightforward layout for personal site maintenance
- No application server needed to run the static pages

## Getting Started

First, make a local copy of the repository:

```bash
git clone https://github.com/loganolntdavis8811/avid-programmer-site-update.git
cd REPO
```

For a local preview, open the main HTML file in your browser. After making changes, commit and push the modified files to the repository and branch used by GitHub Pages.

## Editing and Publishing

Use the following workflow to work on the website:

1. Clone or download the repository.
2. Modify the applicable HTML source files.
3. Check the result in a local browser.
4. Create a Git commit containing the updates.
5. Push the GitHub Pages publishing branch.
6. Visit the deployed website at [https://loganolntdavis8811.github.io/avid-programmer-site-update/](https://loganolntdavis8811.github.io/avid-programmer-site-update/).

The files may be opened directly for local review, or delivered through a basic static-file server during development.

## Site Configuration

There is no application-level configuration file required by Avid Programmer. The site's content and presentation are defined in the website source, mainly within the HTML files.

To enable hosting with GitHub Pages, choose the repository and publishing branch or folder in the repository's Pages settings. The final publishing location is determined by that configuration.

## Frequently Asked Questions

### Where is the live website?

The published site is available at [https://loganolntdavis8811.github.io/avid-programmer-site-update/](https://loganolntdavis8811.github.io/avid-programmer-site-update/).

### What is the process for changing the site?

Edit the appropriate HTML files on your computer, preview the pages, then commit and push the changes to the GitHub repository.

### How do pushed changes reach the website?

GitHub Pages publishes the updated files according to the repository's configured Pages settings after the changes have been pushed.

### Does the project specify a version?

The current project metadata does not define a version value. Use the repository history to review specific changes and publishing activity.

### What can I do if new content is not visible?

Check that the files were pushed to the branch or folder selected for GitHub Pages. If the older page remains, wait for deployment to finish and reload the browser.

### Where are site options maintained?

Make changes to static content and behavior in the HTML source. Hosting-related options are managed through the repository's GitHub Pages settings.
